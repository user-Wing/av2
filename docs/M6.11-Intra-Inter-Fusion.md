# M6.11 单帧快速档与 dsh 帧间工具融合

公开数据包含六组原生与 AOM 单帧测点、测速样本、视频命令参数与各自的码流 SHA-256。下文使用的测试原片由测试者本地提供。替换示例中的 `frame.y4m` 和 `video.y4m` 即可运行相同配置。[实测数据](../benchmarks/m89-fusion.json) · [构建说明](../README.md#构建和单帧编码)

本轮从 M86 的快速单帧和 dsh 的 M88 低延迟 P 起步。六组单帧在 VMAF V1 93–97 整带的等权体积比由 **1.0485× 降至 0.9622× AOM p0**，相对下降 **8.22%**。同时约束 V1 和 NEG 时，体积比由 1.1752× 降至 1.1680×，下降 0.61%。1080p 二维动画仍为 1.0998×，两张二维动画的局部边缘误差都超出与 AOM 的对照门槛。

1080p 二维动画 383 帧全片，dsh 起点的等 V1 体积为 AOM 的 4.613×。本轮在 V1 ≥93 的带内最低值为`full-hold-anchor`，1,703,292 B，V1 93.796、NEG 91.178，等 V1 3.528×、等 NEG 3.771×。全部锚点范围内最低值来自`full-hold`，1,358,890 B，V1 92.265、NEG 89.490，等 V1 3.369×、等 NEG 3.632×。

按该点的 V1，2.00× 对应 965,605 B，当前还需缩减 43.3% 才能达到。

单帧单线程耗时六组等权 **0.985× AOM p0**，六组中位秒数求和为 1.034×。最慢的是 2160p-2D，耗时比 1.279×。

## 单帧工具组合

保留 M86 的 mixed8 分区筛选、矩形 RDOQ、匹配的 DCT64、IBP、帧内边缘滤波及关键帧 GDF。新增 AVM 预定义 QM4、QM8，并保留 QM12。矩阵与 UV AC 量化偏移同时进入码流语法、正反量化、RDOQ 和变换缓存。256 项倒数表按矩阵权重共用。1080p 三组使用 QM4，2160p 动画使用 QM8，2160p 实拍使用平坦矩阵；六组均使用 UV −8。

## 复现与验证

从 SVT-AV2 仓库根目录运行。交付编码器为 MSVC Release AVX2 静态构建，启用 still、speed、DCT64 和 still UV 配置。单帧与视频共用同一套原生实现。

以下单帧命令使用已验证的 1080p 二维动画 Q99。

```powershell
python -B tools/single_frame.py --fusion-gdf --encoder build/bin/SvtAv2EncApp.exe --input frame.y4m --output fusion-1080p-2D.obu --qp 99 --content-type animation
```

以下 PowerShell 命令复现 V1 ≥93 的全片最小体积比。使用新会话，输入为同一 383 帧原片。各视频测点的编码参数、工具环境和码流 SHA-256 见公开数据。

```powershell
$env:SVT_AV2_DCT64_MATCH = 'all'
$env:SVT_AV2_EDGE_INTER = '1'
$env:SVT_AV2_FINAL_SKIP = '1'
$env:SVT_AV2_GDF = 'key'
$env:SVT_AV2_IBP = '1'
$env:SVT_AV2_MOTION_Q = 'hold'
$env:SVT_AV2_QM12 = 'all'
$env:SVT_AV2_QM_LEVEL = '8'
$env:SVT_AV2_UV_DELTA_Q = '-8'
$env:SVT_AV2_VIDEO_RECT = 'all'
& ./build/bin/SvtAv2EncApp.exe --input video.y4m `
  --output fusion-video.obu --frames 383 --export-recon fusion-recon.yuv --qp 131 `
  --threads 1 --pred-structure low-delay-p --intra-select adaptive --partition-select adaptive `
  --rd-mode pruned --deterministic --motion-opt quarter --preset 4 --entropy-adapt on `
  --key-qp 76 --anchor-qp 92 --inter-fine rd --dual-ref-period 4 --dual-ref-policy block `
  --dual-ref-cadence adaptive --inter-near rd --inter-tail rd --cdf-inherit on `
  --rd-lambda avm-ai --rd-lambda-scale 250
```

最终程序在 383 帧上完整复现了 hold 锚帧组合，码流 SHA-256 与该组合的原始测点相同。
