# M6.4 追赶 SVT-AV1 p6

上一阶段 383 帧动画的 3.528× 以 AOM p0 为分母。本轮换用 SVT-AV1 p6 默认随机访问，并在近年三个短片上分别匹配 V1。可复核的同组三片起点 drawing-rd 约为 p6 的 1.242×，最终为 1.013×。后续帧仍为 1.572×。以下给出搜索与参考结构、各配置的消融和长片段复测。

1920×1080、10 位 4:2:0。以官方 SVT-AV1 p6 默认 CRF 随机访问（p6-default）为主对照，另列禁用 AQ 的固定 Q 随机访问和低延迟 P。目标是原生 AV2 在等 V1 下整段平均体积不超过默认 p6 的 0.90 倍。

每个测点均用冻结解码器输出逐帧评分，原生流还校验全段重建 SHA-256。SVT 码量扣除了 IVF 文件头和包头。后续显示帧和全段分别沿实测非支配前沿在 log(字节) 上内插到 V1=95，禁止外推。隐藏锚归入携带它的时间单元。三个 24 帧短片按片等权计算比值的算术平均。《Estab Life》的 64 帧复测含同一片头，单独列出。

## 实现和解码验证

- 16 帧参考层级将隐藏锚及中间参考帧保存在独立槽中。双向块可选两套空间预测向量，或显式传输第二支位移差。8 位和 10 位预测均在合成之后舍入。[预测单测](compound-unit.log)
- 每个叶块独立比较单向、双向、带残差和跳过残差的选择，按实际超块上下文计算码率。隐藏参考帧也可使用等距双向预测。[17 帧真人裁剪](anchor-rd-crop.log)
- 更宽的运动搜索支持 63 像素位移和对应的 AVM 自适应熵模型。261 帧测试覆盖显示顺序和从第 240 帧独立寻址。[外解](wide-smoke.log) · [大位移语法单测](wide-unit.log)
- 时间依赖 QP、按连续画稿分配 QP、仅在隐藏参考帧进行运动补偿时间滤波，以及扩大位移后的逐参考搜索，均作为独立实验档进行整段比较。
- `pyramid-tpl` 在关键帧提交之前读取一组后续源图，以 32×32 区域的运动匹配和预测误差沿实际参考树向前传播收益。其空间版本按超块调整模式选择的拉格朗日乘子。[逐帧 QP 和空间权重 API 单测](tpl-sb-api.log) · [空间预测外解](tpl-sb-smoke.log)
- `pyramid-root-rect` 支持让 64×32 或 32×64 的运动块独立选择参考图，并支付实际的分区和变换系数码率。[裁剪外解](root-rect-crop.log)
- `pyramid-bank` 根据重建画面的分区误差，从现存解码参考槽中选择过去参考图。保留未来参考图的显示顺序，跨组也校验外解。[物理槽与寻址测试](bank-smoke.log)
- `pyramid-span-rd` 对候选帧组长度做动态规划，分别估计各区域用左右参考预测的成本。23 帧实景复测发现的大位移单参考边界差异，按 AVM 的 16 像素边界规范修正。[实景逐帧一致性](span-crop2.log) · [261 帧验证](span-smoke.log) · [边界单测](edge-predictor-test.log)
- `pyramid-quality` 合并双参考逐块细化、64×32 与 32×64 根分区、63 像素搜索和空间时间依赖权重。[261 帧与独立寻址](quality-smoke.log)
- `pyramid-joint-rd` 在双参考平均后的亮度预测上细化第二支运动向量，依次考察整像素、半像素和四分之一像素，再以实际超块代价决定是否采用。[真人裁剪与逐帧外解](joint-rd-crop.log)
- `pyramid-quality-joint` 在空间时间依赖与大矩形分区上使用同一联合预测搜索。[裁剪外解](quality-joint-crop.log)
- `pyramid-local-reuse` 在整帧亮度变化较小的候选上再检查三个平面的 8×8 局部差异，以保护变化的线条。单独重复《迷宫饭》的已解码首帧时，后 23 帧 V1 为 72.73，说明全帧平均差不足以判断是否可重复显示。[首帧重复显示诊断](held-key-diagnostic.json) · [真人裁剪](local-reuse-crop.log) · [261 帧外解](local-reuse-smoke.log)
- `pyramid-reuse-drawing` 查找编码顺序中已可用的相近父参考，提高重复画稿的量化步长，保留新画稿的时间依赖分配。[真人裁剪](reuse-crop.log) · [跨关键帧验证](reuse-smoke.log)
- `pyramid-held-drawings` 检查相邻曝光的源图。连续三帧以上接近同一画稿时，对 Y、U、V 分别融合局部相近的样本以保留变化的边缘，仍对原始输入与真实外解评分。[23 帧真人裁剪](held-crop.log) · [261 帧与独立寻址](held-smoke.log)
- `pyramid-chroma-budget` 是色度量化对照，在整合方案上把色度 Q 偏移从 −8 改成 +8。[裁剪外解](chroma-crop.log)
- `pyramid-inter-matrix` 用每张预测帧实际生效的量化步长选择亮度与色度矩阵，沿用 zenrav1e 的量化步长曲线。[23 帧真人外解](inter-matrix-crop.log) · [261 帧与独立寻址](inter-matrix-smoke.log) · [三个量化点帧内码流与重建回归](matrix-still-regression.log)
- `pyramid-protected-roots` 对同一直接复用估计做反向实验，把更多码量分给后续画面经运动补偿依赖的关键帧和组根。[真人裁剪](protected-crop.log) · [261 帧与独立寻址](protected-smoke.log)
- `pyramid-direct-roots` 对关键帧和组根的量化分配加入源图可直接复用的显示次数估计，其余节点沿用分区时间依赖。[裁剪外解](direct-crop.log) · [跨关键帧寻址](direct-smoke.log)
- `pyramid-short-rd` 在最多 8 帧的参考组上复用同一套多参考逐块搜索与 63 像素搜索范围，可与最多 16 帧的 `pyramid-multi-rd` 对照。[261 帧与独立寻址](short-smoke.log)
- `pyramid-contrast` 把 zenrav1e 的 8×8 对比度失真用于帧间残差、跳过残差和重复显示的裁决。[裁剪外解](contrast-crop.log)
