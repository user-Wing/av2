# M6.3 帧间、帧内工具与速度优化

HD 24 帧初测接近同一 V1 时，原生码流为低延迟 AOM 的 13.18 倍。四分之一像素搜索、分层量化与长期参考逐步压缩后续帧。383 帧二维动画上，dsh 达到等 V1 的 4.613 倍，加入帧内工具和锚帧决策后，在 V1 ≥ 93 的测点达到 3.528 倍。两次测试的片长和质量匹配方法不同。以下按原阶段保留测点、参数和取舍；历史产物路径作为实验编号保留。

## M6.3：帧间编码与速度优化阶段报告（M63–M79）

**M63–M79 阶段归档。** 本报告汇总截至 2026-11-20 的 17 份逐轮实验记录，区分已实现、已测得和未验收的结果。随后以此基线开启的 2D 单帧体积和帧内收益迁移实验，见 [M6.4 / M80](M6.4-2D-Intra-Transfer.md)。最新的原生 GDF、六组复测及后续 P 帧归因见 [M6.9 / M85](M6.9-GDF-Six-Groups.md)。

### 1. 最终成果与验收结论

- **帧间能力：** 从单参考、固定整数运动的低延迟 P，扩展到 SHARP 亚像素、两个物理参考槽与两个逻辑参考、逐块 LAST/LONG、原生含奇数分量的 Q3 运动、有限 16×16、重建感知刷新、P 帧残差尾部剪枝、主参考 CDF 继承，以及现有 NEARMV/DRL0 的独立 RD 竞争。仍是立即显示的低延迟 P，**没有实现 AVM 式重排 GOP、隐藏参考或双参考复合预测**。逐块在 LAST 和 LONG 中二选一不等于同一块混合两个参考。
- **1080p 体积：** 全长 383 帧，较本阶段稳定的自适应刷新、无残差尾剪基线，组合结果 **3,038,885 → 2,913,256 B（−4.13%）**，VMAF V1 **94.299314 → 94.439391**，NEG **92.596311 → 92.696223**。这是两个实际编码点；量化也做了重分配，不是单个工具的因果收益，也不是精确同分或逐帧画质无损。最后一次 NEARMV 质量恢复点单独较 CDF+tail 基线 **−0.705%**，两项均分分别提高 **0.010 / 0.042**。
- **速度：** 最大一项是 M76 的粗分区像素／变换前缀复用，同码流短窗交错计时墙钟中位数 **1080p −32.59%、2160p −33.76%**。M79 在此基础上再复用粗分区熵率前缀，同码流墙钟中位数 **1080p −6.05%、2160p −3.17%**。均为有并发负载的内部开关对照，**不相乘作为累计提速，也不当作对 AOM 的结果**。
- **兼容性：** 最强 1080p 2D Q100 单帧的完整 OBU、编码器重建、固定 AVM 解码重建的 SHA-256 均与冻结基线一致。M79 在真实 1080p/2160p 窗口逐候选核对 **525,120** 次 Q12 码率，完整码流不变。[单帧回归](../artifacts/m79-inter/still-exact/compare.json) · [1080p 逐候选](../artifacts/m79-inter/1080p-every-candidate/audit.json) · [2160p 逐候选](../artifacts/m79-inter/2160p-every-candidate/audit.json)
- **未达成 AOM p0 目标。** 正式低延迟 AOM p0 Q22 全片 **738,335 B**，V1/NEG 都比当前 SVT 全片 P97 点高；当前 SVT 在这两个观测点用了 **3.95 倍**体积。这个差距不是同质量倍率，但已足以否定接近体积目标的判断。完整同质量曲线、2160p 正式锚点和对 AOM 的隔离测速仍缺失。[正式曲线覆盖](../artifacts/m79-inter/acceptance-hd-row0-q28.json)

#### 为什么不能直接移植 AVM

审计所用上游 main 为 [`1cfda4fa`](https://github.com/AOMediaCodec/avm/tree/1cfda4fa4879ef2da411b02fe2f51597daab3451)，本地只读工作树为 `01803db6`，固定解码验收仍用 AV2 v1.0.0 `966a7d7c`。三个版本身份不能混用。

1. **GOP 与 DPB 是一个整体。** AVM 的隐藏参考、overlay、显示与编码重排、槽刷新、逻辑参考排名、order hint 和时间 MV 投影互相依赖。SVT 起初只有立即输出的同显示顺序、单槽 P；增设物理槽、用位流语法映射逻辑参考、扩展逐块选择，必须分别验证。KEY 后不能凭空制造一个已有效的 LONG；时间投影也不能在编码侧强行截断规范预测器来躲开非法候选。
2. **亚像素是一条闭环。** 原实现的整像素搜索和有限预测器，不能只替换为 AVM 卷积核：负相位、Q3/Q4 精度、4:2:0/4:4:4 的色度坐标、边缘复制、MVD 可表示范围、RD 和正式写码必须一致。对于双参考，直接平均两个已裁剪的单参考预测不是规范复合结果。
3. **参考、概率与速率决策有状态。** AVM Q9 rate 与 SVT Q12 rate/Q8 λ 的尺度和失真组合不同，速度阈值不能照搬。试探会影响 CDF、MV 网格和后续块；必须能回滚，并跟正式写码一致。跨帧 CDF 使用实际逻辑 rank 指向的物理槽，包括跨 Q 桶模型，不是“把上一帧 CDF 存下来”。
4. **复合预测不是多一个候选这么简单。** SELECT 帧上符合条件的单参考块也要发复合标志；邻块参考计数与 MV 栈不再能用单向量表示。即使零个复合块胜出也有信令成本；复合像素必须保留中间精度，最后统一舍入和裁剪。本阶段只审计了最小可行的同向 LAST/LONG、等权 `NEAR_NEARMV`，未将其接入编码器。

### 4. 完整视频结果

#### 1080p 2D：383 帧，实际编码点

| SVT 路径 | P/A/K | 字节 | VMAF V1 | VMAF NEG |
| --- | ---: | ---: | ---: | ---: |
| 自适应刷新 + BLOCK/FINE，tail 关闭 | 100/92/76 | 3,038,885 | 94.299314 | 92.596311 |
| 加 tail，保持原 Q | 100/92/76 | 2,746,332 | 94.077963 | 92.399274 |
| tail，恢复量化；CDF 关 | 98/91/76 | 2,965,659 | 94.419225 | 92.648886 |
| 同 Q 加 CDF | 98/91/76 | 2,933,939 | 94.429409 | 92.654498 |

- **tail：** 同 Q 的 −9.63% 伴随双指标下降；实际 P98/A91 恢复点相对无 tail **−2.41%**，V1/NEG +0.120/+0.053。CDF 在这个恢复点上以同一 Q 进一步省 **1.07%**，两项均分均升。

## M6.4 / M80：2D 单帧体积与帧间迁移

后续见 [M6.5 / M81：CfL 单帧搜索、真实 AVM 模式计数及 KEY/P 迁移](M6.5-CfL-Transfer.md)。

**阶段结论：新版 AVM 明确给出了低于 0.95× AOM p0 的实测单帧锚点；SVT 尚未达到整段质量带 0.95×，也未验收帧间叠加。** 本轮把上游的候选收益分解，并把两个不增加位流语法的候选接到 SVT。默认构建和默认运行路径均不变。

### 口径

从 [M6.3 / M79](M6.3-Inter+Speed.md) 继续。M79 的“约 4×”是完整视频中两个**不同质量**的观测点，不是相同质量的单帧、视频或速度比例。此前约 1.07× 是另一个静帧曲线质量区间上的结果，不把它当所有 2D 源的均值。

- AOM 使用冻结 r13 的 AV1 p0 all-intra；AVM 使用上游 [`1cfda4fa`](https://github.com/AOMediaCodec/avm/tree/1cfda4fa4879ef2da411b02fe2f51597daab3451) 的 good-quality p9，单线程，不把两个 preset 当成同速度。AVM 的 x86-64 构建关闭两个 TFLite 相关可选项；Windows 的三个 CDEF SSE 编译单元单独关闭优化，详见[构建补丁](../artifacts/m80-intra/avm-local-build.patch)。AVM p0 的 HD Q96 单线程点 2400 秒超时，不计入对照。
- 两边使用完全相同的原生 10-bit 4:2:0 源、按分辨率选择的 VMAF V1/NEG 模型；计完整 OBU。SVT 以及报告中成功的 AVM 点均以冻结 AV2 v1.0.0 解码器核对原生重建。程序、源、模型和码流 SHA 见逐点记录。
- 比较器在实测未被支配点上按质量分段线性插值 `log(bytes)` 并积分，只在双方交集计算，不外推。等 V1 和等 NEG 是两条独立曲线，**不是两个质量分数同时相等**。视频固定 Q、两项分数变化、整流和仅 P 字节分开报告。

因此优先检查 SVT 现有 CfL 是否能在各树候选、KEY、P-intra 等路径对完整 UV 模式成本公平竞争。现有 still 搜索先按未量化预测 SSE 每平面选 2 个显式 alpha，再从这 4 对做真实 RD，可能漏掉另一色度平面应设零、或量化后率更低的组合。应先做显式 alpha/隐式 CfL 的精确叶率消融，同时检查 CfL 的收益是否来自它改变了树或 luma 候选，而不只是 UV 模式。第二优先是小范围 IST 或上游级别的逐系数优化，而不是把本轮 EOB 剪尾当成完整 trellis；编码块矩形候选与变换分割是两个不同问题。

迁到视频时，必须把 CfL 是否可写与 `m5_intra_modes` 解耦，而不是切到 still 预设：序列开关开启后，即使 UV 选 DC 也必须编码 CfL 的零符号；P 的 inter 邻居要清除色度 CfL 上下文，回滚和 CDF 继承都要核对。第一道关闭候选的对照仍打开序列位并编码合法零符号，只有这样才可能用逐字节相同的 KEY 分离 P-only 候选收益；另用真正禁用序列位的 M79 对照量化固定语法成本。

### SVT 实作和诊断

1. **共享帧内弱 EOB。** 构建开关 `SVT_AV2_EXPERIMENTAL_INTRA_EOB`，运行时 `SVT_AV2_INTRA_EOB=all|key|p`。在选中的完整 SB 上，试做一次/至多四次扫描末尾弱等级删除；因果重放后用实际适应性 CDF 对整 SB 核对率与失真，只接收更小码率及更低 RD 成本的路径，再次独立重放检查最终状态。候选仅限方形 8..64 DCT 帧内残差，不动现有 M74 的帧间残差剪尾。见 [RD 主路径](../Source/Lib/Encoder/rd_frame.c#L4740-L4774)。
2. **64 边匹配正变换。** 基于上游 [`71b3f02`](https://github.com/AOMediaCodec/avm/commit/71b3f0228355f263ad082989994ccb136e5b888d)。原来取 64 点 DCT 的前 32 频点；现在对 64 边相邻残差求和，应用 32 点核，保留原尺寸 shift、归一化、packed stride 和量化尺度。AV2 逆变换在 64 边上本来就是 32 点逆变换后做像素复制，正变换仅调整编码器投影，不改逆变换或语法。构建开关 `SVT_AV2_EXPERIMENTAL_DCT64_MATCH`，运行时 `SVT_AV2_DCT64_MATCH=all|key|p`。见[实现](../Source/Lib/Transform/transform.c#L794-L854)及[独立矩阵参考](../tests/unit/test_transform.c#L298-L334)。

| 1080p 2D-01 | 412 | 1,045 | 1,021 |
| 1080p 2D-02 | 457 | 859 | 473 |

### 单帧：量化 alpha 联合试算

[`rd_frame.c`](../Source/Lib/Encoder/rd_frame.c) 的 `SVT_AV2_EXPERIMENTAL_CFL_PAIR_RD` 需编译开启且设置 `SVT_AV2_CFL_PAIR_RD=1`。在 fast still 的完整 420 叶，保留旧 SSE 前二、显式 alpha 0、±1 和首位的相邻值；每平面每候选只做一次生产量化、逆变换与裁剪，再用活 CDF 的完整 Y/U/V 写码试算联合 pair。不把 U/V 率相加，也不修改试算前缀；叶胜者对独立生产重放必须重现 Q12 和 RD，随后仍走整 SB 门槛。最终 luma 模式上另重试 DC/隐式 CfL。这是有界队列，不是上游 alpha 搜索逐行移植，也不是全部 288 个显式 pair 穷举。

[1080p 2D-01 开启结果](../artifacts/m81-cfl/still-hd01-on/summary.json)：Q100 38,216 B / V1 95.2210 / NEG 92.6042；Q102 36,115 B / V1 95.0275 / NEG 92.2322。两点固定解码逐像素匹配。与[同一二进制的关闭组](../artifacts/m81-cfl/still-on-vs-off.json)相比，Q100 同 Q V1 −0.5654、Q102 +0.1033；在窄交集上，等 V1 体积 **+1.69%**（V1 95.027–95.221），等 NEG **−0.15%**（NEG 92.232–92.575，同时 V1 平均 −0.2524）。因此不默认开启此候选。从 [Q100 追踪](../artifacts/m81-cfl/still-hd01-on/points/1080p-2D-01-cflpair-q100/encode.log)和 [Q102 追踪](../artifacts/m81-cfl/still-hd01-on/points/1080p-2D-01-cflpair-q102/encode.log)，50–54 万次 pair 试算分别得到 2,517/2,216 次局部、已复核的改进，含 750/854 次单零 alpha；包括解码轨迹未采用的 SB/树候选，不能当作最终码流块数。对冻结 AOM p0，[两点等 V1 的比例](../artifacts/m81-cfl/still-vs-aom.json)为 1.088× 和 1.067×，等 NEG 为 1.012× 和 1.013×。只覆盖窄区间，不是 93–97 带的验收。

### 视频：先把 KEY 复用验证到 P

## M6.6 / M82：帧内二次变换与 KEY/P 迁移

### 实现与范围

- `SVT_AV2_INTRA_IST=off|signal|key|p|all` 为私有实验选项，默认关闭。视频使用 M79 的自适应低延迟 P 和跨帧 CDF 继承。单帧使用自适应 4:2:0 fast still。序列位允许亮度帧内 IST，`signal` 编码必要的零符号供同 KEY 对照。P 帧中使用帧内预测的块可参与同一搜索。
- 在已选超块树内，从亮度主变换为 DCT_DCT 或 ADST_ADST、边长至少 8 的帧内叶中，按低频 AC 强度选一个候选。分别试算 21 或 12 个合法二次变换，按量化后 EOB 筛掉不可编码的候选。对完整 YUV 重建和当前自适应 CDF 做整超块 RD，实际估算率与 RD 均降低才采用，再独立重放核对像素、系数和 Q12 率。这个范围将上游变换机制接进当前编码器，AVM 的联合预测、主变换、二次变换与 trellis 搜索仍有更大的搜索域。[RD 实现](../Source/Lib/Encoder/rd_frame.c) · [系数写码](../Source/Lib/EntropyCoding/coeff_syntax.c)
- 正反变换采用 AV2 v1.0.0 的 48 系数支持区、模式相关转置、规范舍入与裁剪。按映射后的宽角模式编码核集合。50,688 个核系数、1,584 个支持区映射和两套集合映射与固定解码器及新版 AVM 一致。七个 CDF 行的初始边界核对了规范附件并追加到现有模型表，随 M79 的 CDF 快照和参考继承一起提交。[AV2 规范](https://av2.aomedia.org/v1.0.0/#secondary_transform_tables) · [表生成器](../tools/gen_intra_ist_tables.py) · [CDF 核对](../artifacts/m82-ist/normative-cdf-check.json)

### SVT 实现

- **混合矩形树**由 `SVT_AV2_STILL_RECT_RD=1` 开启。在现有 `mixed8` 完成基本率失真搜索后，以最好的混合树为种子，每个 32×32 象限独立试两种切法，共八次。32×16 和 16×32 可与其他象限的细分块混用。最低成本新树进入现有完整工具与 RDOQ 复选，使用已有 AV2 二叉分割语法和同一 tile rate/writer。[分区几何](../Source/Lib/Common/block_geometry.c) · [RD](../Source/Lib/Encoder/rd_frame.c)
- **最终亮度模式上的色度重选**由 `-DSVT_AV2_EXPERIMENTAL_STILL_UV_RD=ON` 构建并以 `SVT_AV2_STILL_UV_RD=1` 开启。在方向、MRL、主变换和显式 CfL/MHCCP 已确定后、最终 RDOQ 前，试隐式 CfL、DC 和 SAD 排名前二的普通色度模式。复用同一亮度重建，候选以自适应三平面实际语法率排序。接受前独立重放核对缓存与非缓存路径的率和 RD，再通过超块门槛。[色度复选](../Source/Lib/Encoder/rd_frame.c)
- **帧内边缘滤波**由 `SVT_AV2_STILL_EDGE_FILTER=1` 开启。在仍使用最近参考线的方向预测中，按 AV2 根据角度、块尺寸和上方/左侧相邻模式选择滤波强度。候选从当前树的已重建前序块读取模式，跨超块只读取已提交状态。序列信令配合重建闭环。[方向预测](../Source/Lib/Prediction/intra_prediction.c) · [AV2 边缘滤波规范](https://av2.aomedia.org/v1.0.0/#intra_edge_filter_process)
